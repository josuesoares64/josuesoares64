## 🚧 Projetos em destaque

### 🏭 Sistema ERP de Produção (Autoflex)
**Fullstack | Next.js, Node.js, PostgreSQL**

- 🧠 **Regras de Negócio:** Algoritmo de alocação de recursos que interrompe produção com base na indisponibilidade de insumos e prioriza produtos com maior retorno financeiro  
- 📊 **Simulação:** Sistema "what-if" com cálculos em tempo real, sem persistência no banco  
- ⚙️ **Arquitetura:** Backend estruturado em camadas (Controller, Service, Model)  
- 🗄️ **Banco de Dados:** Modelagem relacional com normalização, associações N:N e integridade referencial (Sequelize)  
- 📈 **Métricas:** Cálculo dinâmico de produção, valor potencial e lucro estimado  

🔗 Front-end: https://github.com/josuesoares64/front-end-autoflex  
🔗 Back-end: https://github.com/josuesoares64/teste-autoflex
